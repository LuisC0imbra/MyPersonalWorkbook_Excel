# Excel Personal Workbook | Formulas, Functions & Data Analysis

### Microsoft Excel Knowledge Base — Beginner to Advanced

A comprehensive Microsoft Excel workbook developed as a personal knowledge base, combining practical examples, formulas, functions, and productivity techniques to support data analysis, reporting, and efficient spreadsheet management.

The workbook contains **62 worksheets**, organized into different learning levels and designed to provide a structured reference for Excel functionality, from fundamental calculations to advanced formulas and dynamic arrays.

## Project Overview

The objective of this project was to build a centralized and reusable Excel reference workbook, documenting essential functions, analytical techniques, and practical examples.

The workbook is structured into three main learning levels:

- **Beginner:** Fundamental Excel operations, calculations, formatting, and cell references.
- **Intermediate:** Logical functions, conditional calculations, lookup functions, data validation, and filtering.
- **Advanced:** Dynamic arrays, advanced lookup techniques, statistical functions, and complex calculations.

It also includes a dedicated navigation index and a collection of additional Excel tips.

## Workbook Contents

### 1. Beginner — Excel Fundamentals

Introduction to essential Excel functions and spreadsheet operations.

**Topics covered:**

- SUM, COUNT, COUNTA, AVERAGE, MIN, and MAX
- Absolute and relative cell references
- AutoSUM, AutoFill, and Flash Fill
- Named ranges
- Number, date, and time formatting
- Cell, row, and column formatting
- Error handling
- Format Painter

### 2. Intermediate — Data Processing & Logical Functions

Development of more advanced spreadsheet techniques for data manipulation, validation, and analysis.

**Topics covered:**

- IF, IFS, and nested IF statements
- AND and OR logical operations
- COUNTIF, COUNTIFS, SUMIF, SUMIFS, AVERAGEIF, and AVERAGEIFS
- IFERROR and IFNA
- VLOOKUP, HLOOKUP, and XLOOKUP
- INDEX and MATCH
- OFFSET and INDIRECT
- Data validation and worksheet protection
- Sorting and advanced filtering
- SORT, SORTBY, UNIQUE, and FILTER
- Date and time calculations
- WORKDAY, NETWORKDAYS, and DATEDIF

### 3. Advanced — Dynamic Arrays & Analytical Functions

Exploration of advanced Excel capabilities for more flexible and efficient spreadsheet calculations.

**Topics covered:**

- Dynamic arrays and traditional array formulas
- SEQUENCE and RANDARRAY
- RANDBETWEEN
- XMATCH and two-way lookups
- CHOOSE and SWITCH
- MEDIAN and MODE
- LARGE, SMALL, and RANK
- COUNTBLANK
- Rounding functions
- MROUND, CEILING, and FLOOR
- AGGREGATE

### 4. Navigation & Productivity Tips

The workbook also contains additional resources to improve usability and productivity:

- Dedicated navigation index for accessing different topics
- Excel tips and shortcuts
- Text manipulation functions
- Custom AutoFill techniques
- Image-related Excel features
- Practical examples and reference material
